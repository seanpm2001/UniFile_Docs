Ideas I don't like

.everyfile

A file format that can function as any type of data, all under the same extension.

How it works:

UniFile/Everyfile

MIME example

A clusterfuzz of an interpreter is used that is capable of running any image/video/audio/document/program/data/stream format, contained in a file (such as example.everyfile) that is structured like this: 

```
UF:|=BIN|{image/PNG}|goto:end》
[BINARY DATA]
EOF
```

This project will never be production ready. It is far from a proof of concept. Please do not attempt to develop or use it professionally! If created, it will make all file formats (except for *.everyfile) obsolete, and would make all computer systems rely on a single program (an everyfile interpreter)
